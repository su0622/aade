# 视觉编码

本阶段把叙事模块落实为设计表达。使用 [视觉编码表](视觉编码表.csv) 标注字段、图元、视觉通道、尺度和版面角色。为主模块画两种草图，比较阅读顺序、标签归属与读数体验。

| 表达手段 | 设计记录 |
| --- | --- |
| 点、线、面、体 | 明确点定位的对象、线连接的顺序或关系、面承载的分区或面积。使用体量时记录量值如何映射及透视造成的读数差异。 |
| 色彩 | 记录色相对应的类别、明度对应的序列、强调色对应的叙事重点。 |
| 字体、行距、字距 | 记录标题、读数、正文、注释的字号与层级，以及字距、行距和对齐方式。 |
| 图像与图形 | 记录照片、插画、图标的选择、裁切、位置、图注与来源。 |
| 统计图形 | 记录尺度、单位、刻度、基线与表示比较或变化所用的图形。 |
| ISOTYPE（ISO 图形） | 记录等大图符的单位值、重复次数与余量处理。可参照 [03 ISOTYPE 专项](../../03-IOSTYP信息图/README.md)。 |
| Gestalt 原则 | 记录接近、相似、共同区域等线索如何支持分组与读图。可参照 [04 Gestalt 专项](../../04-Gestalt知觉组织与信息图形设计/README.md)。 |
