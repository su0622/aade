# 主题内容分析

使用 [大模型沟通模板](大模型沟通模板.md)，将调研材料、数据样本和目标读者带入对话。把模型提议、支持证据、需要核对的信息和最终决定记在下表。

| 判断项 | 判断依据 | 项目结论 |
| --- | --- | --- |
| 01 主数据逻辑 | 按时间变化读为编年型，按类别和条目读为编目型，按层级结构、字母顺序、地理位置读时分别考虑层级型、字母表型、地理图形。 | 待填 |
| 视觉风格 | 平面风格可用于强调符号与抽象关系。照片风格可用于展示可辨认的具体对象、现场或形态，可结合插画与统计图。 | 待填 |
| 02 主表现标签 | 根据画面主要承载方式选一项。候选包括词云信息图、文字型与列表型信息图形、图片式信息图形（照片型方案）、时间轴型等。 | 待填 |
| 辅助表现标签 | 记录承担局部叙事或比较任务的标签及其使用位置。 | 待填 |
| 待验证问题 | 记录相互竞争的方案及所需证据、材料或数据。 | 待填 |
