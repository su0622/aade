# 基础数据集构建

使用 [基础数据集.csv](基础数据集.csv)、[字段字典.csv](字段字典.csv) 和 [数据清洗记录](数据清洗记录.md)。先写明一行代表的观测单位，例如一个地点在一个统计期的一项指标。

- **一行一条记录，一列一个字段，一格一个值。** 同一列的语义、类型与单位口径应一致。一列可以有多行，每行该列只填一个原子值。
- 名义数据填一个类别或名称。量化数据填单个数值，单位、币种与统计期按需分列。
- 地点的纬度与经度分成两列，各存一个数值。图像字段填一个文件路径或图像 ID，文字字段填一段作为单个观测单元的原文或一个文本 ID。
- 多图、多标签、多段文本等一对多关系用关联表展开，每行记录一次关系。多个指标按各自独立字段或逐行的长表记录。
- 缺失值留空，缺失原因单独记录。证据通过来源 ID 回链，页码、表号或时间码可单列。

模板以“地点 × 统计期 × 指标”为默认观测单位。实际项目根据观测单位调整列，并同步更新字段字典。
