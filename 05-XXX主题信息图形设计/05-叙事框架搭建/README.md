# 叙事框架搭建

用 [叙事字段映射表](叙事字段映射表.csv) 把已经核对的字段组合成可回答的读者问题，再安排开场、主体与收束。

| 读者问题 | 字段组合 | 叙事与图形 |
| --- | --- | --- |
| 某地点在哪里、有何信息？ | 对象名称 + 纬度 + 经度 + 文本值 | 在地图上标点，标签显示地名，注释给出地点信息。 |
| 某地在某年 GDP 是多少？ | 对象名称 + 指标名称（GDP）+ 数值 + 单位 + 币种 + 统计期 | 用柱形、数字或表格比较地区 GDP，标题注明年份与口径。 |
| 事件如何演进？ | 事件名称 + 时间 + 文本值 | 按时间排列事件，读者沿节点了解变化。 |

为每个叙事模块记录证据、筛选或计算规则、图形载体及阅读顺序。没有足够字段支持的问题登记回数据搜集阶段。
