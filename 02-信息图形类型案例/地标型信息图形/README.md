# 地标型信息图形

借地图、地名、位置或路线建立空间参照。

## 分析与制作要点

记录地点 ID、坐标或地理关联键、地理口径和指标。从空间位置读到数值，再沿引线回到实体。需要区分引线、真实路线和流量边。
