# 混合型信息图形（Mixed Charts）

统计图形与符号、ISO 图形或其他图形元素共同承担读数、定位或解释任务。记录每种元素表达的变量及其在阅读顺序中的作用。采用 ISO 图形时标注标准编号或可核验来源。

## 跨案例归纳

先给每个模块指定统计、定位或解释任务，再确定叙事顺序。连续指向的引线负责关联，带宽只有在设定口径时才表达数量。

## 分析与制作要点

按统计、符号与叙事三层拆解。比较常用条形或点图，构成宜先检查分母和类别可加性，地理统计须匹配地理键。标准图符的来源与 ISOTYPE 式重复图符的计数单位分别记录。
