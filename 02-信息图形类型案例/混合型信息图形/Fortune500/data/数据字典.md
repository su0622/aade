# 基础数据字典

| 文件 | 一行代表 | 字段与口径 |
|---|---|---|
| [都市圈营收](都市圈营收.csv) | 一个入图都市圈 | 排名、英文名称、营收（十亿美元）、原图数值与单位、换算值、计量货币及出处。以都市圈为统计对象。 |
| [正文数字](正文数字.csv) | 正文的一项事实 | 主体、指标、值、量纲、年份、适用范围、原文措辞和精度。空白年份按缺失处理。 |
| [视觉编码](视觉编码.csv) | 一种图形要素 | 视觉变量、所表达字段、数据类型、可复原程度与说明。 |
| [来源与提取边界](来源与提取边界.csv) | 一项溯源或口径说明 | 图像版本、数据范围、精度及缺失信息。 |

按排名对照两仓库，15 个都市圈的营收值全部一致。旧表部分记录带有导出行索引，读取时按主字段识别。

《Fortune》正文明确指出，2019 年的 2.04 万亿美元为旧金山、圣何塞、西雅图三地入榜企业营收的合计。主图三地数值相加为 2,042.3 十亿美元，与正文约数相符。
