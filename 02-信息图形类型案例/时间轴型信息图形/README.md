# 时间轴型信息图形（Timeline Infographics）

示例来自用户提供的课件。

以连续轴线、方向标记或依序排列的节点呈现事件和阶段。节点可附日期、解释与量化小图，持续事件可用条带表示。注明日期精度、断轴，以及时间间距是否按比例绘制。

## 案例

- [包豪斯与格罗皮乌斯](包豪斯与格罗皮乌斯/案例分析.md)
- [电视节目年代轴](电视节目年代轴/案例分析.md)

## 分析与制作要点

分开记录时间点、起止区间和主体分轨。需要读出时长时，轴位置按时间尺度映射，并说明精度和断轴。阶段顺序与事件因果分别记录。
