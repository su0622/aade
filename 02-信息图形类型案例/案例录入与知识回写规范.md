# 案例录入与知识回写

1. 先按数据的主导关系判定一个 01 类型，再选 02 表现主标签。辅助标签用链接关联。复合图、同题不同设计、分幅要说明关系。
2. 每张案例图和其 `案例分析.md`、`基础数据集.csv` 存在同一案例子目录。记录作品及图像版本、来源页码和归档方式。保存基础数据，记录单元、关系、统计、视觉编码、叙事及制作流程。
3. 采用一行一条记录、一列一个字段、一格一个值。类别、对象、指标、数值、单位、时间、来源、证据状态分别存列。每个指标独立成行；上下界拆列；一对多关系拆行或使用关联表。CSV 使用 UTF-8，说明文档提供可直接查看的表格。
4. 数值列只写数值，空白表示缺失而非零。转录值、计算值和结构观察分别标注。保留公式、量纲、尺度和口径。需要重制而源数据缺失时先登记可辨认结构，注明无法继续转录的范围。
5. 更新 02 案例索引、标签 README 和对应 01 定义的文字链接。01 只链接案例。单例注明出处，多个案例互证后再将共性和制作规则回写至 01 或 02。
