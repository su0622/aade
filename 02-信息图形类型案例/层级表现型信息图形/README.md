# 层级表现型信息图形

用缩进、嵌套、分层或大小突出统属关系。

## 分析与制作要点

登记节点、父节点和层级。颜色可区分分支，面积可编码可聚合数值。版面中的标题大小用于检索时，应与数据层级分开记录。
