# 文字型／列表型信息图形（Informational / List Infographics）

示例来自用户提供的课件。

标题、短文和列表条目承担主要信息表达。通过对齐、字号、留白和重复模块明确阅读顺序。配图和符号可提示条目含义，小型统计图可补充数量关系。

## 跨案例归纳

标题先让读者识别主题，重复条目再支持扫描及横向比较。通过字母索引、成员名或图符键建立可追踪的定位关系。

## 分析与制作要点

一行可对应一个条目，记录分组、标题、序号、解释与来源。编号可作定位码，若表达排名，还需写明评价指标与排序方法。附百分比时说明分母和基准。
