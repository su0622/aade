# 解剖型信息图形

通过剖面、拆分视图和引线解释对象的构件及关系。

## 分析与制作要点

为部件建立 ID，记录位置和连接关系。区分比例示意和实际尺寸，避开引线交叉，并在局部图与整体图之间保持标号一致。
