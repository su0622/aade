# ISOTYPE 基础设计方法

ISOTYPE（International System of Typographic Picture Education）通过一致的图符、排列与图例，把统计关系转成可读的图像。它在本仓库是跨类型的基础设计方法标签。一张作品先确定 01 主数据逻辑与 02 表现标签，再补记使用的设计方法。

## 视觉编码

- **图符形状**帮助识别对象，必要时用文字标注补足确切含义。
- **重复数量**表达量值。比较同一指标时，用更多同尺寸图符表示更大的值，并在图例注明每枚图符代表多少。
- **排列与颜色**帮助分组对照。共用起点和间距，颜色对应明确的类别或指标。

## 制作流程

1. 整理对象、类别、指标、数值与单位，统一比较口径。
2. 选定每枚图符的代表量，把各数值换算为图符数。涉及半枚图符或取整时，注明处理规则并保留原始数值。
3. 用一致的尺寸与间距排列图符，在图例中标明代表量和色彩含义。检查读者能否从图符数回读数量。

归档时检查图符是否用来编码数量或组织比较，并记录图符与数据的对应。仅用图标装饰的作品仍可按其原有表现标签检索。
