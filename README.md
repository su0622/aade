## 案例收录与更新

1. 在 02 中为每个表现标签设独立目录。ISOTYPE 案例归入 03，Gestalt 教学示意归入 04，后续完整项目案例归入 07，相关 02 标签提供索引。每个案例在所属标签下单独建目录，将案例图和对应的 `案例分析.md` 放在一起，附上来源、可取得的基础数据与口径说明。发布原图前确认授权。原图缺失时注明，基础数据随案例存放。
2. 在案例中记录主数据逻辑、表现标签、统计与计算、视觉编码、信息架构、视觉叙事和制作流程。区分可复核观察、复制作法与待查信息。
3. 在 01 的相应定义文档及 02 的标签说明中增加指向案例报告的 Markdown 相对链接。01 目录只保留定义与文本链接。
4. 每次收录案例时，同一提交回写受影响的定义、原则和方法。单例注明出处，多案例对照后再提升为通用原则，补记例外与适用条件，提交说明记录本次新增证据和修改范围。

基础数据采用一行一条记录、一列一个字段、一格一个值。图、说明和 CSV 同目录，数值、单位、年份与来源分列。详见[案例录入与知识回写](02-信息图形类型案例/案例录入与知识回写规范.md)。
