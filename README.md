## 案例收录与更新

1. 在 02 中为每个表现标签设独立目录。每个案例在所属标签下单独建目录，将案例图和对应的 `案例分析.md` 放在一起，附上来源、可取得的基础数据与口径说明。发布原图前确认授权。原图缺失时注明，基础数据随案例存放。
2. 在案例中记录主数据逻辑、表现标签、统计与计算、视觉编码、信息架构、视觉叙事和制作流程。区分可复核观察、复制作法与待查信息。
3. 在 01 的相应定义文档及 02 的标签说明中增加指向案例报告的 Markdown 相对链接。01 目录只保留定义与文本链接。
4. 每次收录案例时，同一提交回写受影响的定义、原则和方法。单例注明出处，多案例对照后再提升为通用原则，补记例外与适用条件，提交说明记录本次新增证据和修改范围。
